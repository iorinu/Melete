Melete アイコン案 v4 — G / I ダーク配色

v3 で選ばれた案G Fold（折面）と案I Weave（織）の形・配置はそのままに、色と光だけをダークファンタジー寄りに組み直しました。配色は3系統で、G と I に同じ名前の配色を当てています。形ごとに選んでも、配色ごとに揃えて選んでも比較できます。

配色ごとの比較

各行の左が配色の説明、右が G と I です。G は「背景＝闇・上の帯＝淡い金属色・下の帯＝宝石色」、I は「背景＝宝石色・明るい帯＝淡い金属色・暗い帯＝闇」と、色の役割を両案で揃えています。各アイコンの横に 64px / 32px をライト・ダークの両背景で並べました。

比較の基準です。形・配置・配色とも v3 から変えていません。

メモ

  • 形のパス・座標・重なり順・回転は v3 と同じです。変えたのは塗り・グラデーション・影の色と濃さ、縁の線の太さ（3→4）、背景の奥に置いた光、G の下帯の背後に置いた発光（帯と同じ形をぼかしたもの）だけです。
  • 発光はどの配色でも形の背後に滲ませるだけにして、輪郭そのものは光らせていません。32px でも縁が太って見えず、形がはっきり残るようにするためです。
  • I は暗い帯を闇色にしたので、宝石色の背景の中央に光を置いて帯の輪郭を浮かせています。
